**Goal:** Подключить блок «Наценка по брендам» вкладки ценообразования админки (`MarkupTab`) к реальному backend `pricing/brand-markups` (list / upsert / delete) через `@tanstack/react-query`. **Architecture:**

- Токен читается из `useAuthStore(s => s.accessToken)`.

**Tech Stack:** React 19, TypeScript ~5.8, `@tanstack/react-query` ^5.101, Vite 6, Tailwind 4, Zustand. Сборка/типизация: `npm run lint` (алиас `tsc --noEmit`). Дев-сервер: `npm run dev` (порт 3000).

  export interface BrandMarkup {

    brand: string;
    markupPercent: number;
    createdAt: string;
    updatedAt: string;
  }

  export interface UpsertBrandMarkupBody {

  export const pricingApi = {

    list: (token: string): Promise<BrandMarkup[]> =>
      apiRequest<BrandMarkup[]>('/api/pricing/brand-markups', { token }),

    /** PUT /api/pricing/brand-markups — создать/обновить наценку (ADMIN). */
    upsert: (token: string, body: UpsertBrandMarkupBody): Promise<BrandMarkup> =>

    remove: (token: string, brand: string): Promise<void> =>

      ),
