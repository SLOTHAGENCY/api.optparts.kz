# test-frontend — одноразовый тестовый фронт

Минимальный статический фронт **только для ручного тестирования API** агрегатора:
регистрация, вход, поиск по артикулу, корзина (с живой перепроверкой цен), оформление
заказа, список заказов с под-заказами партнёров. **Дизайн не важен.** Без сборки и
зависимостей — чистый HTML + `fetch`.

## Как запустить

Вариант 1 — раздать тем же бэком:
1. В `.env` поставить `SERVE_TEST_FRONTEND=true`.
2. Запустить API (`npm run start:dev`).
3. Открыть `http://localhost:3000/test/index.html`.

Вариант 2 — открыть файлы напрямую (`file://.../test-frontend/index.html`). Работает,
т.к. CORS у API открыт (`*`), а токен хранится в localStorage. При этом API должен быть
запущен на том же origin, иначе поправь `API_BASE` в `app.js`.

## Сценарий smoke-теста

Регистрация → (редирект на поиск) → поиск артикула → «В корзину» у нужного оффера →
вкладка «Корзина» (видно живую перепроверку цены/наличия) → «Оформить заказ» →
вкладка «Заказы» (заказ с под-заказами партнёров и статусами).

## Как удалить одним движением

1. Удалить эту папку `test-frontend/`.
2. В `src/app.module.ts` убрать блок ServeStatic, помеченный
   `// TEST FRONTEND — удалить вместе с папкой test-frontend/`.
3. Убрать `SERVE_TEST_FRONTEND` из `.env` / `.env.example`.

Больше нигде фронт не упоминается.
